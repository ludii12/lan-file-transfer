# 局域网文件传输

手机和电脑在同一个 WiFi 下，互相传文件、传文字，还能把手机语音转成文字直接送到电脑上。
电脑端是一个 Ant Design 风格的小窗口，手机端就是一个网页——不用装 App。

## 功能

- **传文件**：手机浏览器打开就能上传（支持拍照、录视频、相册）和下载，电脑端拖拽也行
- **文字互传**：两端共用一份文字历史，电脑上传手机、手机传给电脑
- **语音输入**：按住手机网页上的麦克风说话，松手自动识别、自动发送到电脑
  - 识别**完全在电脑本地**跑（sherpa-onnx + Paraformer），不经过输入法、不上云
  - 识别完自动补标点
  - 电脑端自动复制到剪贴板，可自动粘贴到当前窗口
  - 空闲 10 分钟自动释放模型内存（约 450MB），下次用自动重载
- **开机自启**：写 HKCU 注册表启动项（360 会拦「启动」文件夹的快捷方式）
- 浅色 / 深色两套配色

## 环境

- Windows 10/11，Python 3.10+
- 手机和电脑连同一个路由器
- 语音功能需要模型文件（约 300MB，见下）

## 快速开始

**Windows 最省事：双击 `启动.bat`。** 它会自动检查 Python、装依赖（直连失败自动切清华镜像）、
下载模型（约 300MB，仅第一次），然后打开程序。

手动方式：

```bash
# 1. 装依赖
pip install -r requirements.txt

# 2. 下载语音模型（约 300MB，只做传文件可以跳过）
python 04_下载模型.py

# 3. 启动
python 01_启动.py
```

启动后窗口里会显示二维码，手机扫码即可用。默认端口 8000，界面里可以改。

开机自启：电脑界面勾「开机自动启动」，或手机语音页右上角齿轮 → 「开机自启动」，
两边改的是同一个注册表项，会互相同步。

## 手机端

| 入口 | 作用 |
|---|---|
| 标题旁「语音」 | 按住大麦克风说话，松手自动识别并发送；上方大字预览，可上滑取消 |
| 标题旁「文字」 | 输入文字传到电脑；「历史记录」默认收起，只显示文字记录，不和语音混在一起 |

`选择文件` / `照片 / 视频` 分别对应任意文件、图片和视频的相册选择。

### 网页录音需要 https

浏览器规定：http 页面拿不到麦克风。所以程序会额外起一个 https 端口（默认 `端口+1`）。

1. 手机打开 `http://<电脑IP>:1000/cert`，里面是可以点的安装步骤和「测试安全连接」
2. 装好证书后，用 `https://<电脑IP>:1001/` 打开，就能在网页里直接按住说话
3. 不装也能用：http 页面上点麦克风会打开系统录音机，录完自动上传识别

## 开机自启

界面里勾「开机自动启动」即可；也可以用命令行：

```bash
python 03_开机自启.py        # 查看状态
python 03_开机自启.py on     # 开启
python 03_开机自启.py off    # 关闭
python 03_开机自启.py test   # 按自启方式立刻跑一次
python 03_开机自启.py 防火墙 # 放行防火墙入站（手机打不开时用）
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `01_启动.py` | 主程序：GUI + HTTP/HTTPS 服务 + 语音识别 |
| `web/index.html` | 手机端页面 |
| `02_自检.py` | 接口自检（上传/下载/删除/文字/设置），不需要 GUI |
| `03_开机自启.py` | 开机自启与防火墙 |
| `04_下载模型.py` | 下载语音识别和标点模型 |
| `模型/`、`证书/`、`文字记录.json`、`config.json`、`分享文件/` | 本机数据，**不进仓库** |

## 安全说明

- 服务**没有密码**：同一局域网内任何人都能打开页面、上传、下载、删除共享文件夹里的文件。只建议在自己家的网络里用。
- `证书/lan.key` 是 https 的自签私钥，**不要提交、不要外传**。手机把它装成 CA 后，等于无条件信任它签发的任何证书。
- 语音模型和录音都留在本机，不会上传到任何第三方。

## 已知限制

- 只在 Windows 上测过（开机自启、防火墙、证书都用到了 Windows 专有接口）
- 证书绑定 IP，路由器给电脑换了地址后手机需要重装一次（建议固定 IP）
- 识别模型是中文 Paraformer，英文和中英混说效果一般
