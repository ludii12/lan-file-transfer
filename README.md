# 局域网文件传输

手机和电脑在同一个 WiFi 下，互相传文件、传文字；还能把手机语音转成文字直接送到电脑上。

电脑端是一个 Ant Design 风格的小窗口，手机端就是一个网页——不用装 App，扫码即用。

## 功能

- **传文件**：手机上传（任意文件 / 相册照片 / 录像）和下载，电脑端支持拖拽上传；中文文件名、大文件流式传输
- **文字互传**：两端共用一份文字历史；语音和文字分开存，找以前传过的文本不会被语音刷掉
- **语音输入**：按住手机网页上的麦克风说话，松手自动识别并发送
  - 识别**完全在电脑本地**完成（sherpa-onnx + Paraformer），不经过输入法、不上云
  - 识别完自动补标点
  - 说话过程中每约 1.2 秒出一次预览，边录边出字
  - 上滑取消，误触不发
  - 电脑端自动复制到剪贴板，可自动粘贴到当前窗口
- **省资源**：模型懒加载，不用语音只占约 55MB；空闲 10 分钟自动卸载，内存回到约 80MB
- **开机自启**：写当前用户注册表启动项，不占用「启动」文件夹
- 浅色 / 深色两套配色

## 环境要求

- Windows 10 / 11（开机自启、防火墙、证书都用了 Windows 接口）
- Python 3.10 或更高
- 手机和电脑连同一个路由器
- 语音功能需要模型文件，约 310MB

## 快速开始

### 一键启动（推荐）

双击 **`启动.bat`**。它会依次：

1. 检查 Python，没有就提示下载地址
2. 检查依赖，缺了就装（直连失败自动切清华镜像）
3. 检查模型，缺了就下（约 310MB，只有第一次）
4. 打开程序

### 手动

```bash
pip install -r requirements.txt   # 装依赖
python 04_下载模型.py              # 下模型（只做传文件可以跳过）
python 01_启动.py                  # 启动
```

启动后窗口左侧有二维码，手机扫码即可打开。默认端口 **8000**，可以在界面里改。

## 手机端用法

标题右边有两个入口：

| 入口 | 作用 |
|---|---|
| **语音** | 按住大麦克风说话，松手自动识别并发送。上方是预览区，识别过程中实时出字；按住后上滑 70px 可取消 |
| **文字** | 输入文字传到电脑；「历史记录」默认收起，只存文字类，不和语音混在一起 |

主界面的 `选择文件` / `照片 / 视频` 分别对应任意文件和相册里的图片、视频。

语音页右上角齿轮里还有三项设置：

- **自动粘贴到电脑**：电脑收到后自动复制并 Ctrl+V 到当前窗口
- **模型常驻内存（450MB）**：手动加载 / 释放识别模型；空闲 10 分钟也会自动释放
- **显示输入框**：语音页多出一个输入框，用来打字发送（停顿 1.6 秒自动发）

### 网页录音与证书

浏览器规定：**http 页面拿不到麦克风**。程序因此额外开了一个 https 端口（默认 `端口+1`）。

1. 手机打开 `http://<电脑IP>:8000/cert`，里面有图文步骤、下载按钮和「测试安全连接」
2. 把证书装成 **CA 证书**
3. 用 `https://<电脑IP>:8001/` 打开，就能在网页里直接按住说话

不装证书也能用：点麦克风会打开手机自带的录音机，录完自动上传识别，只是没有"按住说话"。

界面里的「手机访问地址」和二维码，在有证书时默认指向 https 地址。

## 开机自启

电脑界面里勾「开机自动启动」即可。也可以用命令行：

```bash
python 03_开机自启.py        # 查看状态
python 03_开机自启.py on     # 开启
python 03_开机自启.py off    # 关闭
python 03_开机自启.py test   # 按自启方式立刻跑一次，验证可用
python 03_开机自启.py 防火墙 # 放行防火墙入站（手机打不开时用，需要管理员授权）
```

360 安全卫士会拦启动项改动，弹窗时选「允许 / 加入白名单」，否则会被它悄悄删掉。

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机打不开网页 | 确认在同一 WiFi；跑一次 `python 03_开机自启.py 防火墙` |
| 地址变了 | 电脑换了网络，点界面「刷新地址」，二维码会跟着变 |
| 端口被占 | 界面里换个端口再点「启动服务」 |
| 手机点麦克风没反应 | 用的是 http 页面且没有系统录音机；装证书改用 https |
| 识别不准 | 目前是中文 Paraformer 模型，英文和中英混说效果一般 |
| 想验证功能 | `python 02_自检.py` |

## 安全说明

- **服务没有密码**：同一局域网内任何人都能打开页面、上传、下载、删除共享文件夹里的文件。只建议在自家网络中运行。
- `证书/lan.key` 是 https 的自签私钥，**不要提交、不要外传**。手机把它装成 CA 后，会无条件信任它签发的任何证书。
- 语音模型和录音都留在本机，不会上传到任何第三方。
- 证书绑定电脑 IP，路由器换地址后手机需要重装一次；建议在路由器里给电脑固定 IP。

## 已知限制

- 只在 Windows 上测试过
- 识别模型为中文，英文效果一般
- 同时开多个实例会抢端口

## 实现要点

- HTTP/HTTPS 用标准库 `ThreadingHTTPServer`，上传走 `PUT` 流式写盘
- 手机端单页，无框架；上传用 `XMLHttpRequest` 带进度
- 语音识别：`sherpa-onnx` + `paraformer-zh`（int8，234MB），标点用 `ct-transformer`（77MB）
- 录音在浏览器用 `MediaRecorder`，每约 1.2 秒把"到目前为止的整段音频"重跑一次做预览
- 解码任意音频格式（webm / m4a / wav）用 PyAV 重采样到 16k
